# 📊 市场高频体温与行业动量周报

> 基于同花顺股票与板块交易数据构建的轻量化周度量化看板，专为敏捷跟踪市场情绪与结构性主线而设计。

---

## 💡 项目介绍

在宏观数据滞后且冗余的背景下，本项目摒弃了传统的“大而全”报表，专注于**高频、直观、结构化**的周度体感雷达。通过抓取全A个股行情、市场真实成交额以及申万行业动量，每周自动生成一份兼具专业深度与公众号极简美学的 HTML 报告，助你快速看清大盘烟火气与领跑优势行业。

---

## 🗂️ 看板与目录结构

本项目采用纯前端静态托管架构，所有历史周报均可无缝归档与切换：

```text
market-weekly-radar/
├── index.html                 # 🌐 主引导页（内置“时光机”下拉菜单，默认展示最新一周）
├── LICENSE                    # ⚖️ 开源许可协议 (CC BY 4.0)
├── README.md                  # 📖 项目说明文档
└── reports/                   # 📁 历年历周生成的子 HTML 报告目录
    └── 2026-11-13.html          # 2026-11-13周报（最新）
